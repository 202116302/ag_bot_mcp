# 비료 처방 전달 비교 결과 — 2026-11-16

현재 범위는 단일 필지·작물의 저장된 공급자 비료 처방 전달이다. 관수는 제외했다.
방법과 분모 정의는 [평가 프로토콜](fertilizer_delivery_protocol.md)을 따른다.

## 실제 GPT 결과

GPT-5.4-mini 고정 버전과 동일 설정에서 질문 4개를 각 경로 10회 반복했다.
첫 실행 묶음은 전체 처방 질문과 로컬 보류 검사, 두 번째는 N/P/K·0 값·출처 질문이다.
두 묶음의 원본·정규화 자료·모델·설정·코드 해시 일치와 질문·시행 중복 없음을 확인했다.

| 항목 | MCP | RAG |
|---|---:|---:|
| 모델 전달 시도 | 40 | 40 |
| 수치·단위·식별/출처·고지 및 전달 검증 통과 | 38 | 39 |
| 네트워크 실패 | 2 | 1 |
| 받은 최종 응답의 값 보존·고지 검사 통과 | 38/38 | 39/39 |
| 미등록 필지·작물 로컬 보류 | 20/20 | 20/20 |
| 비교 조건 불일치 | 0 | 0 |

실패를 분모에 남긴 전달 성공은 MCP 38/40(95%), RAG 39/40(97.5%)다.
이는 이번 실행의 연결 실패까지 포함한 관측값이며 농업 정확도나 방법 간 우월성의 근거가 아니다.
원시 값 보존 지표의 전체 시도 분모에서도 실패는 각각 2건·1건으로 남아 있다.

| 질문 | MCP 전달 통과 | RAG 전달 통과 |
|---|---:|---:|
| 전체 처방·한계 | 10/10 | 10/10 |
| 밑거름·웃거름 N/P/K | 8/10 | 10/10 |
| 퇴비·0 값 보존 | 10/10 | 10/10 |
| 출처·작물·검정일자·한계 | 10/10 | 9/10 |

3건 모두 `OPENAI_NETWORK_ERROR`이며 재시도하거나 성공 결과로 대체하지 않았다.
연결 실패를 모델의 수치 왜곡으로 분류하지 않는다. 받은 최종 응답에서는 고정 참조값과의 수치·단위·출처·고지 충돌이 없었다.
다만 구조화 계약과 단일 자료에 대한 결과이며 자유서술·새 자료·일반 검색의 성능을 보장하지 않는다.

반복 일관성은 실패를 포함해 MCP의 N/P/K 질문 0.8, RAG의 출처 질문 0.9이고 나머지 질문은 1.0이다.
이는 원시 구조화 응답의 최빈 값 횟수/전체 시도다. 네트워크 가용성이 포함되므로 순수한 모델 변동성과 동일하지 않다.

## 자동 테스트와 Mock

- 전체 자동 테스트 **175 passed**.
- Mock은 질문4개 ×10회로 경로별40/40 전달 검증 통과, 로컬 보류는 경로별20/20 통과.
- Mock은 결정적 대역이다. 이 결과를 GPT 성능이나 독립적인 농업 정확도로 해석하지 않는다.
- 실제 GPT의 두 실행 묶음과 Mock 로그를 모두 API 없이 재집계했다.
- 네트워크 실패가 포함된 두 번째 GPT 묶음은 정상적으로 종료 코드1과 `all_passed=false`를 반환한다.
  이 값은 발견된 실행 실패의 표시이며 자동 테스트의 코드 오류를 의미하지 않는다.

## 저장 위치

| 종류 | 폴더 |
|---|---|
| Mock 전체 질문집 | `outputs/fertilizer_delivery/20261116T062713026734Z/` |
| GPT 전체 처방·로컬 보류 | `outputs/fertilizer_delivery/20261116T062729068253Z/` |
| GPT 나머지 전달 질문3개 | `outputs/fertilizer_delivery/20261116T063042523842Z/` |
| GPT 두 묶음 종합 CSV·요약 | `outputs/fertilizer_delivery/combined_20261116/` |

각 개별 실행 폴더에는 `protocol.json`, `evidence.json`, 시행별 원본 JSON,
`results.csv`, `summary.json`, `report.md`가 있다. 원본은 보존했다.
종합 CSV는 120행(모델 시도80 + 로컬 보류40)이며 시행·사례·경로 중복 없이 합쳤다.
종합 요약에는 원본 묶음의 프로토콜/요약 SHA-256과 실패 파일 목록이 있다.

다음 명령은 개별 원본에서 보고서를 다시 생성하며 API를 호출하지 않는다.

```powershell
python scripts/compare_fertilizer_paths.py --analyze outputs/fertilizer_delivery/20261116T062729068253Z
python scripts/compare_fertilizer_paths.py --analyze outputs/fertilizer_delivery/20261116T063042523842Z
```

두 번째 명령의 종료 코드1은 같은 3건의 연결 실패를 포함한 재집계 결과다.

## 다음 개선 대상

현재 자료는 1개 처방이며 질문 표현만 달리했다. 다양한 실제 필지·작물·자료 없음·성분 결측 등
응답 상태가 포함된 별도 자료집으로 확장하는 것이 다음 단계다. 동일 필지의 반복을 여러 독립 농장의 표본으로 세지 않는다.
전달 정확도와 분리해서 연결 실패·응답 지연·토큰 사용량을 분석할 수 있으나, 이 소규모 실행으로 인과적인 우열을 주장하지 않는다.
