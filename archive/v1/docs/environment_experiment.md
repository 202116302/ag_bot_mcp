# 환경자료 원본 감사와 고정 조건 반복 평가

2026-11-16. 환경자료·문헌 질의응답을 단일 소량 점검에서 반복 평가로 확장했다.
직접 센서 연결이나 관수·실제 온실 제어는 포함하지 않는다.

## 단위·시각·집계 의미 확인

첨부 PROVIDE 명세, 실제 저장 응답, [스마트팜코리아 공식 Open API 설명](https://www.smartfarmkorea.net/openApi/openApiList.do?menuId=M1104030101)의
환경 정보 출력항목·샘플을 대조했다. 해당 출력 명세는 측정 일시 형식과 String 측정값을 제시한다.
확인한 환경 응답 구간에서 TI/HI/CI 단위, 시간대, 평균 계산 방법을 확정할 설명은 찾지 못했다.
기관 전체에 관련 정보가 없다는 뜻은 아니며, 다른 데이터셋의 단위를 대신 적용하지 않았다.

검토 기록은 `data/references/environment_metadata_review.json`이다.
실행 스냅샷의 단위·시간대·집계 방식은 계속 미확인으로 두며 모델의 적합성·제어 판단 보류도 유지한다.

## 앱과 별도의 원본 감사

`src/agri_dss/environment_audit.py`는 앱의 정규화기와 요약 함수를 호출하지 않고 저장 원본 JSON을 읽는다.
요청 인자, 응답 시설·품목·분야·항목, 업무 상태, 날짜·시각 중복, 결측·유한 수치, 원본 해시,
정규화 레코드와의 일치 및 고정 참조 수치를 직접 대조한다.

| 항목 | 원본 대조 결과 |
|---|---|
| TI | 24건, 최솟값24.67, 최댓값32.33 |
| HI | 24건, 최솟값76.33, 최댓값97.00 |
| CI | 24건, 최솟값401.00, 최댓값506.00 |

| 날짜 | 2023-07-25 |
| 시각 | 수치가 있는 세 항목 모두00:00:00∼23:00:00, 중복 없음 |
| 관찰된 기록 간격 | 시각 문자열을 날짜/시간으로 해석했을 때3,600초 |

72개 수치 레코드에서 결측·중복과 고정 참조값 불일치는 없었다.
한 시간 간격 기록은 원시 센서 측정 주기나 ‘한 시간 평균’이라는 증거가 아니다.
시간대도 이 감사로 확정하지 않는다. 단위가 미확인인 원시 숫자에 ℃·%·ppm을 붙이지 않는다.
위 수치는 농업적 적정 범위의 독립 정답이 아니라 원본 값의 보존을 평가하는 참조값이다.

## 반복 평가 프로토콜

`scripts/run_environment_experiment.py`로 기존5개 모델 처리 질문과4개 로컬 보류 질문을 각10회 실행한다.
각 반복의 경로 순서를 번갈아 실행하고 자동 재시도하지 않는다.
모델·추론 설정, 원본/스냅샷/문헌/질문/프롬프트/스키마/코드 해시를 실행 전 고정한다.
시작 시 원본 감사가 실패하면 모델 실험을 시작하지 않는다.

모델 처리 질문은 전체 조회·일반토마토 온도·방울토마토 온도·습도·CO₂다.
같은 시설·날짜·5개 문헌 문단을 표현과 범위가 다른 질문으로 조회한다. 독립적인 농장5개가 아니다.
로컬 보류는 관수·현재 제어·다른 PNU·다른 시설 요청이며 모델 호출 없이 별도로 평가한다.

| 지표 | 검사 범위 |
|---|---|
| 원시 수치 | 선택 항목·업무 상태·건수·최솟값·최댓값·null 단위 |
| 원시 인용 | 선택 문단 ID 목록의 중복·누락·추가 여부 |
| 원시 한계 고지 | 미확인 단위/시각/적용 조건 등과 판단 보류 상태 |
| 원시 식별·해시 | 시설·날짜·스냅샷·문헌·근거 묶음 해시 |
| 검증된 전달 | 위 계약 및 런타임 검사 통과 후 설명 출력 |
| 반복 일관성 | 원시 구조화 응답의 최빈 값 횟수 / 전체 모델 시도 |

평가기는 마지막 원시 모델 응답을 읽는다. 렌더링된 한국어 문장으로 수치 오류를 숨기지 않는다.
0과 null은 다르게 취급하고 Decimal 표기 및 배열 순서 차이는 정규화한다.
일관되게 틀린 응답도 일관적일 수 있어 값 보존과 반복 일관성을 구분한다.
연결 실패·불완전 응답·거절·형식 오류·검증 충돌·누락/손상 로그는 실패로 보존하고 분모에서 빼지 않는다.
로컬 보류는 모델 처리 점수의 분모에서 제외한다.
실행 조건이 바뀌면 전체 통과를 차단하며, 그런 실행의 원시 점수를 같은 조건의 성능으로 해석하지 않는다.

## 실행과 재집계

```powershell
python scripts/run_environment_experiment.py --repeats 10
python scripts/run_environment_experiment.py --provider openai --repeats 10
python scripts/run_environment_experiment.py --analyze outputs/environment_experiment/<실행시각>
```

`--case`를 여러 번 지정해 일부 사례만 실행할 수 있다. `--repeats`는1∼10회다.
`--analyze`는 저장 파일만 읽고 API 없이 재집계한다.

실행 폴더에 다음을 보관한다.

- `protocol.json`: 고정 질문·참조값·모델 설정·실행 조건·해시.
- `audit.json`: 독립 원본 감사와 원본 파일별 해시.
- `snapshot.json`, `catalog.json`, `metadata_review.json`: 동결 자료와 의미 확인 기록.
- 시행별 원본 JSON: 모델 원문·usage·오류·도구/검색 기록·시간.
- `results.csv`, `summary.json`, `report.md`: 원시 점수·실패 유형·일관성·실행 조건.

동결 자료가 누락·변경되면 비교 조건 실패로 기록한다. 개별 실행 로그가 없어져도 예정된 시행은 실패 분모에 남긴다.
모델 호출 수 필드는 수신한 응답 기록 수이므로 연결 실패 때0일 수 있다. 전체 시도 분모는 예정된 질문별 실행 횟수를 사용한다.
