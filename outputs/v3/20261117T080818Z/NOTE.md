# 예비 실험 (v3.0) — 본 결과 아님

2026-11-17 첫 전체 실행(500 응답). 판정 엔진·시나리오 결함이 발견되어 v3.1로 수정 후 재실행했다.
이 폴더는 비교·기록용으로 보존한다.

수정 내용 (v3.0 → v3.1)
- climate_control_decision: 습도/기온 값이 없으면 판정 문구에 "판단 보류"를 명시 (이전: "조치 불필요")
- nutrient_decision: 판정 문구에 항목별 상태(적정 포함)를 모두 표시, 배액률-근권 EC 충돌을 판정 문구에 명시
- weather_risk_decision: 침수 일수 0이면 피해율을 계산하지 않음
- 기상 시나리오 5개: 작물 정보(노지) 추가, 질문에 "노지 토마토 밭" 명시
- NUT-GH-002: 정답 키를 EC 항목 기준으로 수정
- TSK-OF-002: 문서상 20℃가 '이하'·'이상' 모두에 해당하므로 50배액·100배액 모두 정답 인정, 경계 언급 여부를 필수 항목으로 평가
- nutrient_decision 도구 설명: "질문과 관련된 항목의 값만 넣는다"
