# 토마토 문헌 검토: 관수 기준과 규칙화 가능성

후속 사용자 결정으로 관수는 현재 실험에서 제외했다. 아래는 문헌 검토 보관 기록이며
실행 규칙으로 승격하지 않는다. 현재 범위는 [비료 처방 전달 평가](fertilizer_delivery_protocol.md)다.

검토일: 2026-11-16. 연구 프로토타입의 실제 근거 후보를 선정하기 위한 문헌 검토다.

## 결론

**우선 규칙 후보는 PDF 132쪽(인쇄 129쪽)의 ‘토마토 관비재배 시 텐시오미터 관수개시점’이다.**
이 절은 일반적인 개시점 **−20 kPa**, 일본계 **−20∼−25 kPa**, 유럽계 **−30∼−35 kPa**를 명시한다.
앞서 검토한 PDF 43·249쪽은 생육단계별 수분의 유지 범위다. 서로 다른 범위를 합쳐 개시점을 만드는 것보다
개시점이 직접 제시된 제5장 자료를 사용하는 것이 연구 규칙의 근거로 더 적절하다.

문헌 수치를 확인했다는 것과 실제 필지의 적용 조건·경계 연산자까지 검증했다는 것은 구분한다.
품종, 토양 관비재배 여부, 센서 부호·단위·설치 조건이 확인되기 전에는 실제 필지 처방으로 실행하지 않는다.
후보 기록은 `configs/rules/candidates/tomato_moisture_review.json`에 저장했다.

## 제5장 관수개시점: 적용 범위와 근거의 강도

### 원문으로 확인한 사실

PDF 114쪽은 관비를 관개수에 비료를 녹여 공급하는 방식으로 설명하며 토양의 양분공급력·완충작용을 언급한다.
116∼117쪽은 재배토양의 물리성·pH, 131쪽은 시설 토마토의 근권 토양·과다관수를 설명한다.
이 문맥에 비추어 132쪽은 **시설의 토양 관비재배와 텐시오미터 측정**을 대상으로 해석하는 것이 타당하다.
이는 주변 문맥에 근거한 적용 범위 해석이며, 시설 토마토라는 API 작물명만으로 그 조건을 확인할 수는 없다.
수경·암면·펄라이트 양액재배에 같은 토양 임계값을 자동 적용하지 않는다.

132쪽은 ‘일반적인 관수개시점’을 −20 kPa로 제시하고 품종군별 설정 범위를 별도로 둔다.
해당 문장에는 생육단계별 서로 다른 개시점이 제시되어 있지 않다.
따라서 이 개시점에 제9장의 단계별 유지 범위를 섞어 새로운 단계별 숫자를 만들지 않는다.

같은 쪽의 표 5-12는 농진청 원예원 2008년 시험을 인용한다. 원본 표의 합계 행을 대조했다.

| 관수개시 설정 | 일본계 슈퍼도태랑 수량(kg/10a) | 유럽계 라피토 수량(kg/10a) |
|---|---:|---:|
| −20 kPa | 10,306 | 13,842 |
| −25 kPa | 9,856 | 13,752 |
| −30 kPa | 9,372 | 13,643 |
| −35 kPa | 8,474 | 13,070 |

각 열의 4개 화방 수량과 합계가 일치한다. 표의 착과 수는 슈퍼도태랑 4과/화방, 라피토 5과/화방이다.
이 자료는 품종에 따라 개시점 반응이 다를 수 있다는 근거다. 모든 일본계·유럽계 품종에 대해 같은 효과가
검증됐다는 뜻은 아니다. 이 표만으로 반복 수·오차·검정 방법을 확인할 수 없으므로 통계적 동등성을 새로 주장하지 않는다.
2008년 원 시험의 별도 보고서까지 확인한 것은 아니다.

### 연구용 이진 규칙으로 옮길 때의 제안

문헌의 −20 kPa 자체는 확인된 사실이다. 아래 등호 포함과 운용 정의는 **연구자의 형식화 제안**이다.

| 입력의 의미가 확인된 경우 | ‘기준에 도달하면 개시’로 정의하는 제안 | 경계를 엄격히 넘을 때만 개시하는 대안 |
|---|---|---|
| 음수로 표현한 같은 토양수분장력/매트릭 퍼텐셜의 kPa 값 | `값 <= -20` | `값 < -20` |
| 같은 값의 양수 장력 크기를 표현하는 kPa 값 | `장력 >= 20` | `장력 > 20` |

부호 대응은 같은 물리량을 반대 부호로 표시한다는 센서 계약이 확인된 경우에만 적용한다.
모든 음수 센서값에 절댓값을 취하거나 양수값을 무조건 장력으로 해석하지 않는다.
현재 엔진의 `kpa_tension`은 음수가 아닌 입력이다. 음수 원본은 그대로 넣을 수 없으며,
원시값·원시단위·부호 규약·정규화 근거를 남기는 공급자 어댑터가 필요하다.

연구 프로토콜에는 등호를 포함하는 안과 엄격 경계 안 중 무엇을 채택했는지 먼저 고정하고,
경계 사례 `19.9 / 20.0 / 20.1 kPa`로 차이를 점검하는 것이 좋다.
이 숫자 예시는 실제 센서 정밀도나 관측값을 의미하지 않는다. 센서의 해상도·오차·측정 주기에 맞는
처리와 반복 작동 방지 방식은 별도로 정해야 한다.

이 절은 **관수개시 판단**의 근거다. 물의 양, 관수 종료점, 1회 가동 시간, 종료 후 재개 대기시간,
히스테리시스를 이 −20 kPa 하나에서 도출할 수 없다.

## 센서·단위 관련 중요한 확인

1. **함수율%는 kPa가 아니다.** PDF 125∼126쪽은 함량값을 관수개시 판단에 쓰려면
   토양별 수분 특성 관계를 고려해야 하며 현장 보정을 설명한다. 고정 상수로 변환하지 않는다.
2. **표 5-11은 중량% 표다.** PDF 126쪽 표 머리말에서 직접 확인했다.
   같은 쪽의 TDR 설명이 용적수분함량을 다룬다고 해서 이 표의 숫자를 `percent_vwc`로 읽으면 안 된다.
   예를 들어 표의 사양토·20 kPa 열 19.3은 표 기준 중량%이며 부피함수율 19.3%로 복사하지 않는다.
3. **부호 표기가 섞여 있다.** 일반 설명의 0∼100 kPa와 개시점의 −20 kPa를 문자 그대로 같은
   부호 체계로 취급하지 않는다. 실제 센서의 출력 정의를 확인한다.
4. **설치 위치가 입력의 대표성을 좌우한다.** PDF 132쪽은 근권 내 설치와 점적기로부터
   대략 10∼15 cm 거리, 토성에 따른 반응 속도·설치 위치 차이, 근권 깊이에 따른 설치 깊이를 설명한다.
   여러 깊이의 값을 평균할지·어느 값을 사용할지에 대한 자동 판정 규칙은 여기서 확정하지 않는다.
5. **측정범위는 품질 검사의 근거 후보다.** PDF 125쪽 텐시오미터 설명의 0∼100 kPa를
   다른 센서 제품 전체의 유효 범위로 일반화하지 않는다. 실제 제품 범위와 점검 상태가 필요하다.

## 원문 품질과 잘못된 전사 위험

- PDF 79쪽 원본에는 pF 2.3∼2.5에 **−2∼−30 kPa**가 병기되어 있다. PDF 93쪽의 유사한 문장은
  **−20∼−30 kPa**다. −2 표기는 추출 과정에만 생긴 오류가 아니라 원본 이미지에서도 확인된다.
  오기 가능성으로 기록하고 −20으로 조용히 고치지 않았다. 이 때문에 해당 병기값을 자동 환산 규칙으로 쓰지 않는다.
- 표 5-11은 중량%, TDR/FDR 설명은 용적%다. 표·본문이 같은 페이지에 있어도 변수 정의를 구분한다.
- PDF 132쪽의 관수개시점 품종 범위와 PDF 249쪽의 생육단계 유지 범위는 기능이 다르다.
  서로 다른 숫자를 같은 `threshold` 목록에 넣고 임의 선택하면 안 된다.
- 관수조절 시험에서 당도·수량이 바뀐 결과를 ‘건조할수록 항상 유리하다’는 규칙으로 확대하지 않는다.

## 시비·환경제어 연계에 대한 부수 검토

본 검토의 중심은 관수다. 관련 절에서 다음 연계상의 제한도 확인했다.

- PDF 73쪽은 토양검정과 재배형태·수확단수·밀도 등에 따른 시비량 결정을 설명한다.
  책의 표준 시비량이 현재 선택 필지의 흙토람 공급자 처방보다 우선하는 독립 정답은 아니다.
- PDF 133∼135쪽의 양분 흡수량은 시비량과 같은 변수가 아니다. 수량 목표·품종·재배환경에 따른
  흡수 추정치를 그대로 비료 투입량으로 바꾸지 않는다.
- PDF 77·91쪽의 온도 관리는 작물 유형·시간대·날씨·생육 상황의 문맥을 가진다.
  온실 관측값과 제어 목표·설비 정보 없이 기상 실황 하나로 환기창 명령을 만들 근거로 사용하지 않는다.

다음 구현에는 **시설 토양 관비재배, 확인된 텐시오미터 장력, 명시된 품종 기준**을 입력 계약으로 두는
문헌 기반 연구용 후보가 적절하다. 품종을 모르는 경우 일반 −20 kPa 문장을 쓰는 별도 실험 가정은 가능하지만,
그 가정을 기록하고 품종별 처방으로 제시하지 않아야 한다.
실제 관측 확보 전에도 합성 kPa 사례로 형식화의 동작을 시험할 수 있으나 결과는 계속 합성 시험으로 표시해야 한다.
