# 비료 자료 MCP/RAG 비교: 구현 범위와 프로토콜

2026-11-16 구현. 선택 필지 `5271033027105280033`, 시설 토마토 코드 `04017`의 저장된 공급자 처방을 사용한다.

현재 범위는 사용자 결정으로 관수를 제외한 비료 처방 전달·출처 추적·반복 일관성이다.
후속 고정 질문집·원시 응답 평가·CSV 재집계는 [현재 평가 프로토콜](fertilizer_delivery_protocol.md)을 따른다.
아래 관수·농업 직접 판정 항목은 이전 장기 계획 기록이며 현재 실험의 다음 필수 작업이 아니다.

## 두 경로

| 항목 | MCP | RAG |
|---|---|---|
| 자료 획득 | 모델의 함수 호출 → 실제 stdio MCP 비료 도구 | 선택 PNU·작물로 문서 메타데이터 검색 |
| 모델에 주는 자료 | 정규화 비료 도구 결과 | 같은 정규화 JSON을 포함한 검색 문서 |
| 기본 모델 호출 | 도구 선택 및 설명, 통상 2회 | 검색 근거를 읽고 설명, 1회 |
| 도구 사용 | get_fertilizer_prescription | 없음 |
| 응답 검사 | 공통 구조화 수치·단위·출처·결측·한계 검사 | 동일 |

현재 검색 코퍼스는 선택된 처방 문서 1개다. PNU·작물 일치가 없으면 다른 문서를 대신 사용하지 않는다.
0개 또는 중복 검색, 내용 해시 불일치, 선택된 정규화 자료와의 불일치는 모델 호출 전에 실패로 남긴다.
벡터 검색·임베딩·문헌 청크 검색은 구현하지 않았다. 이 작은 코퍼스에는 정확한 메타데이터 필터를 사용한다.
검색에 쓰는 내용과 MCP 도구 결과는 같은 어댑터를 거치며 정규화 자료 해시를 실행 기록에 남긴다.

두 경로의 지원 범위 검사는 같은 로컬 키워드 규칙이다. 보류 질문은 모델 호출이 없고,
복합 질문은 지원하는 비료 부분만 응답한다. 보류를 GPT 분야 분류 성능이나 모델 응답 일치로 계산하지 않는다.
Mock은 직접 정규화 자료를 복사해 경로를 검증하는 대역이며 모델 성능 평가 대상이 아니다.

## 실행 및 기록

```powershell
$env:PYTHONPATH = 'src'
$env:PYTHONIOENCODING = 'utf-8'
python -m agri_dss ask --path rag --provider mock
python scripts/compare_fertilizer_paths.py --provider mock
python scripts/compare_fertilizer_paths.py --provider openai
```

`--question`으로 같은 질문을 양쪽에 전달하고 `--repeats 1..10`으로 반복 수를 지정한다. 기본값은 1이다.
반복 시 경로 순서를 번갈아 실행하며 모델과 자료를 다시 읽은 결과가 달라지면 비교 조건 불일치로 기록한다.
단일 `ask`는 `outputs/llm/`, 비교 실행은 `outputs/path_comparison/<UTC 시각>/`에 저장한다.

- 각 시행의 `01_mcp.json`, `01_rag.json` 등: 실제 모델 원문·usage·오류·시간·도구/검색 기록·해시·설정.
- `summary.json`: 질문, 시행별 경로 순서, 비교 조건, 오류, 응답 일치 여부와 개별 run_id.
- `report.md`: 개별 원본에서 계산한 계약 점검 결과.

원본과 정규화 자료, 코드, 모델·설정, 질문, 응답 스키마 및 로컬 지원 범위가 같은지 확인한다.
확인된 구조화 응답의 수치를 Decimal로 정규화하고 성분·고지 순서 차이를 제거해 비교한다.
모델 오류·불완전 응답·거절·잘못된 JSON·수치 충돌·RAG 도구 호출은 정상 설명으로 렌더링하지 않는다.
실패한 시행도 저장하고 종료 코드는 1이다. 관측 지연은 로그에 있지만 작은 표본의 속도 우열을 주장하지 않는다.

## 실제 확인

- 전체 자동 테스트: **128 passed**. 미등록 필지/작물, 검색 중복/변조, 근거 없는 수치, 모델/API 실패, 공통 한계 고지, 실제 MCP 왕복과 비교 기록 보존 포함.
- Mock 1쌍: `outputs/path_comparison/20261116T045723494548Z/`.
- 실제 GPT 1쌍: `outputs/path_comparison/20261116T050429871534Z/`.
- 실제 GPT 양쪽 모두 `completed`, 동일 자료·설정 확인 및 구조화 응답 일치.
- 출력 예: 밑거름 N/P/K `14.4 / 3.0 / 3.0 kg/10a`, 웃거름 `10.9 / 0.0 / 0.0 kg/10a`.
  이는 저장된 공급자 처방을 전달한 값이며 자체 규칙의 계산 결과가 아니다.

## 후속 연구 조건

현재 과제는 공급자 처방의 수치와 한계를 보존하는 자료 전달 비교다. 원본 연구 명세의
‘문헌 기준을 LLM이 직접 해석·계산하는 RAG’와 ‘Python 규칙이 판정하는 MCP’ 비교는 아직 남아 있다.
같은 공급자 처방을 두 경로로 전달하는 성공을 농업 정확도나 MCP 표준의 효과로 해석하지 않는다.

1. 적용 작물·시설/노지·생육단계·단위를 명시한 문헌 기준을 확인하고 연구용 규칙으로 확정한다.
2. 관수 수분 관측값과 단위·재배방식을 확보하거나 별도로 표시한 합성 사례에서만 동작을 점검한다.
3. RAG에는 기준 원문과 입력을, MCP에는 같은 입력과 확정 규칙을 전달한다. RAG에 Python 판정 결과를 주입하지 않는다.
4. 경계·복합조건·계산·누락 사례별 독립 정답과 허용 오차를 먼저 고정한다.
5. 모델·설정·자료를 고정한 10회 반복과 실패를 포함하는 정확도·일치율·출처 추적 지표를 산출한다.

독립 정답 기반 정확도 수치와 포스터용 연구 결과 그래프는 이번 산출물에 포함하지 않았다.
