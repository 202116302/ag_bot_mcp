# 과거 환경자료와 토마토 재배문서 질의응답

후속 [원본 감사·고정 조건 반복 평가](environment_experiment.md)를 추가했다.
아래 버전별 소량 점검과 고정 버전의10회 반복 결과는 구분한다.

2026-11-16 구현. 데이터마트의 과거 환경 스냅샷을 토마토 재배문서와 함께 조회하는 별도 경로다.
직접 센서를 연결하지 않으며 관수는 제외한 상태를 유지한다.

## 할 수 있는 질문

- 저장된 과거 토마토 환경자료의 온도·습도·CO₂와 문헌 근거를 보여줘.
- 일반토마토 온도관리 문헌과 과거 환경값을 보여줘.
- 방울토마토의 온도관리 문헌은 어떻게 달라?
- 과거 습도 자료와 재배문서의 관련 근거를 보여줘.
- 저장된 CO₂ 자료와 문헌에서 검토할 부분을 알려줘.

질문의 주제와 일반/방울토마토 지정에 따라 자료 항목과 인용 문단을 선택한다.
유형을 지정하지 않으면 온도 적응성, 일반토마토 관리, 방울토마토 관리의 별도 문맥을 구분해 제시한다.
질문에 방울토마토라고 썼다는 이유로 데이터마트 시설의 품종이 방울토마토라고 확인되는 것은 아니다.

## 실제 입력과 문헌

환경 입력은 `SMARTFARM-PFS_0000001_01-20230725`의 2023-07-25 기록이다.
TI·HI·CI 각24개, HI02 자료 없음 상태를 보존한다.
API 단위·시간대·집계 방식·품종·생육단계가 미확인이라 현재 수치 적합성 판단은 보류한다.
이 시설을 기존 비료 PNU에 연결하지 않는다.

원본 『농업기술길잡이106 토마토』 2020년 판에서 다음 다섯 문단을 이미지와 대조해 등록했다.

| ID | PDF / 인쇄 쪽 | 내용·문맥 |
|---|---|---|
| tomato-temperature-adaptation | 41 / 38 | 생장·발달·착과에 적합한 낮21∼29.5℃, 밤15.5∼21℃의 적응성 범위 |
| tomato-general-temperature-management | 77 / 74 | 일반토마토 오전25∼28℃, 오후23∼25℃, 일반 야간15∼17℃; 별도 변온관리·흐린 날·지온 문맥 포함 |
| tomato-cherry-temperature-management | 91 / 88 | 방울토마토 오전·오후와 일몰 이후·새벽을 구분한 관리 일정 |
| tomato-air-humidity | 42 / 39 | 공기습도65∼80% 정도의 참고 범위; HI의 측정 의미와 동일시하지 않음 |
| tomato-co2-review | 42 / 39 | CO₂와 광조건 설명; 단위 병기·상한 설명을 추가 검토 대상으로 보존 |

일반토마토와 방울토마토의 야간 관리 일정을 합치거나 적응성 범위를 재배 관리 일정으로 바꾸지 않는다.
CO₂ 문단의 mg l⁻¹·ppm 병기와 상한 설명은 자동 임계값으로 사용하지 않았다.
원문 확인용 이미지·텍스트는 `outputs/source_review/environment_reference/`에 있다.
등록 문단은 `data/references/tomato_environment.json`이며 PDF 원본과 문단 텍스트의 해시를 확인한다.
문단 요약은 검토 후 작성한 표시용 자료이며 자동으로 검증된 제어 규칙이 아니다.
전체364쪽을 벡터 색인한 검색이 아니라 검토한5개 문단의 주제·토마토 유형 필터다.

## 두 경로

| 항목 | MCP | RAG |
|---|---|---|
| 자료 획득 | 모델이 get_environment_context 도구 호출 | 선택 항목의 원시 관측값과 관련 문단을 직접 전달 |
| 건수·최솟값·최댓값 | Python이 계산해 도구로 반환 | 실모델이 원시 값에서 읽고 계산 |
| 문헌 | 같은 검토 문단 | 같은 검토 문단 |
| 출력 항목 | 같은 구조화 스키마 | 같은 구조화 스키마 |
| 검사 | 식별·해시·수치·자료 없음·인용·한계 고지 | 동일 |

RAG 입력에는 Python이 구한 건수·최솟값·최댓값을 주입하지 않는다.
출력할 항목 코드와 인용 ID 목록은 검색·요청 범위에서 정해 양쪽에 제공한다. 이 목록은 숫자 정답이나 시험 라벨이 아니다.
MCP 함수 인자의 시설·토마토 유형·허용 주제는 모델 스키마에서도 요청 범위로 제한하고 실행 전에 다시 검사한다.

모델 원문은 보존하고, 통과한 구조화 수치와 인용 ID를 기준으로 검토된 문헌 요약과 한국어 설명을 출력한다.
모델의 자유서술 의미 전체를 검증하거나 임의의 문헌 주장을 사실로 승인하는 기능은 아니다.
null 단위는 원시 숫자를 숨긴다는 뜻이 아니다. 수치 조회와 문헌 적합성 판단을 구분한다.
HI02의 자료 없음은0건·null 최솟값/최댓값으로 유지한다.

정상 결과는 `partial`이다. 자료 조회와 문헌 제시는 완료했으나 환경 적합성·설비 제어 판단은 보류했음을 뜻한다.
관수·오늘 상태/제어·다른 시설·PNU 환경 요청은 모델 호출 전에 `deferred`로 처리한다.
분기는 제한된 로컬 키워드 규칙이며 일반적인 자연어 의도 분류 성능을 주장하지 않는다.

## 구현과 실행

- `src/agri_dss/environment_context.py`: 검토 문단 로딩·검색, 환경 숫자 요약, 판단 범위.
- `src/agri_dss/environment_assistant.py`: 전용 Mock·GPT, MCP/RAG 경로, 출력 검사와 한국어 렌더링.
- MCP `get_environment_context`: 등록 과거 자료와 문헌의 묶음 조회. 실제 제어를 수행하지 않는다.
- CLI `environment-ask`: 기존 비료 `ask`와 별도로 사용한다.
- `scripts/check_environment_qa.py`: 고정 사례의 원시 수치·인용·보류 계약 점검 및 원본 저장.

```powershell
$env:PYTHONPATH = 'src'
$env:PYTHONIOENCODING = 'utf-8'
python -m agri_dss environment-ask --provider mock --path mcp
python -m agri_dss environment-ask --provider openai --path rag --question "과거 습도 자료와 토마토 재배문서의 관련 근거를 보여줘."
python scripts/check_environment_qa.py
python scripts/check_environment_qa.py --provider openai
```

`--output`으로 로그 경로를 지정하고 `--json`으로 원문·도구/검색 기록·해시·설정·검증을 확인할 수 있다.
개별 실행은 `outputs/environment_qa/`, 사례 점검은 `outputs/environment_qa_checks/<시각>/`에 저장한다.
환경 데이터마트를 매 질문마다 재호출하지 않고 고정한 자료를 사용한다.

## 검증 과정

전체 자동 테스트 **231 passed**. 항목/문헌 선택, 원문 변경, 단위 창작, null/0, 수치·건수·날짜 변조,
인용/고지 누락·중복, 다른 시설·작물·PNU·날짜·관수·현재 제어 요청, 도구 인자·원본 불일치,
모델 거절·불완전 응답·네트워크 실패, CLI와 실제 stdio MCP 왕복을 포함한다.

실모델 첫 점검에서 전체 조회의 인용 누락과 RAG의 요청하지 않은 항목 추가/자료 없음 항목 누락이 발견됐다.
검사기는 이를 차단하고 사용자 답변을 출력하지 않았다. 출력 항목·인용 목록을 명시하도록 계약을 보완했다.
후속 점검에서 MCP가 미확인 단위 때문에 원시 숫자를 비운 응답과 요청하지 않은 토마토 유형을 고른 호출이 차단됐다.
원시 수치 보고와 적합성 판단 보류를 구분하고 함수 인자 스키마를 요청 범위로 고정했다.
오류가 나온 실행도 삭제하거나 성공 결과로 덮어쓰지 않았다.

이 점검은 환경자료·인용 전달 계약에 대한 소량 실행이며 농업적 적합성이나 제어 정확도 평가가 아니다.
각 버전의 원본·코드·입력·프롬프트 해시를 보존하며 서로 다른 버전의 실행을 반복 실험으로 합산하지 않는다.

- 최신 Mock: `outputs/environment_qa_checks/20261116T080040501293Z/report.md`.
- 최초 GPT 실패 보존: `outputs/environment_qa_checks/20261116T075503429262Z/`.
- 중간 보완 GPT 기록: `outputs/environment_qa_checks/20261116T075810476022Z/`.
- 최종 GPT 보고서·원문: `outputs/environment_qa_checks/20261116T080104677509Z/`.

실행 폴더에 protocol.json, 개별 경로 원본 JSON, summary.json, report.md가 있다.
최초·중간 실패는 제거하지 않았고 자동으로 올바른 값이나 인용으로 바꾸지 않았다.
이는 문헌 인용·원시 수치 보존의 기능 점검이며 환경 적합성·일반 검색·자유서술 사실성이나 농업 성능 지표가 아니다.
