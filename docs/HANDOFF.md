## API 실조회 핵심 결과

### 비료사용처방

공통: 인증키를 사용한 실제 호출. HTTP 200과 업무 결과코드는 별도로 해석한다.

| PNU_Code | 작물 조건 | 실제 결과 |
|---|---|---|
| `5211110100100120003` | `04017` 시설 토마토 | `301 요청 데이터 없음` |
| `4571033027106720012` (명세서 예시) | `00001` 벼, 쌀품질 `1`, 혼합비율 28/22/19 | `301 요청 데이터 없음` |
| `4571033027106720012` | `04017` 시설 토마토 | `301 요청 데이터 없음` |
| `5211300000` | `04017`, 사용자가 준 10자리를 그대로 전달 | `201 요청변수 형식 불일치` |
| `5211100000` | 위 실패 후 순차 조회, `04017` | `201 요청변수 형식 불일치` |

중요: 기본 19자리 PNU는 **형식 오류 응답이 아니었다**. `301`만으로 PNU 자체 오류, 자료 삭제, 행정코드 변경, 모든 작물의 자료 부재를 단정하면 안 된다. 사용자에게 이 차이를 여러 차례 설명했다. 같은 요청을 이유 없이 반복하거나 계속 주소를 요구하지 않는다.

필지 조회는 기존 토양검정자료가 필요하다. 체험 V2는 토양 화학성 입력 기반이며 아직 호출하지 않았다. 해당 서비스 승인 여부와 필수 분석값 확보가 필요하다. 임의 분석값을 실측값처럼 사용하지 않는다.

### 스마트팜

- PROVIDE 아이덴티티 2319레코드, 토마토 품목 531레코드. 대표성 있는 연구 표본이 아니라 조회 목록이다.
- 최초 토마토 농가 3곳 작기 조회 성공. 과거 작기와 재배방식 누락/상세 코드가 있다.
- 첫 농가 최신 등록 작기 5957의 환경 첫 페이지는 읽기 20초 제한으로 시간 초과.
- 같은 농가 `PFS_0000001_01`, 2023-07-25의 내부온도 TI 24레코드 조회 성공.
- 같은 농가·날짜의 토양함수율 MC와 수분장력 MT는 `03 NODATA_ERROR`.
- 이 결과를 다른 농가·날짜까지 데이터가 없다는 뜻으로 확대하지 않는다. 실제 관수 입력으로 사용할 수분값·단위는 아직 확보하지 못했다.
- PROVIDE 토마토 코드는 `080300`, CROPSEASON 명세에는 `80300` 표기가 있다. 원본 코드를 문자열로 유지한다.

### 기상

- 사용자가 제공한 서버: `http://weather-rda.digitalag.kr:8001/docs`.
- 공개 OpenAPI는 `docs/weather_openapi.json`에 저장.
- `전주시` 조회는 빈 배열. 지역 목록에는 `전주시완산구`, `전주시덕진구`가 있다.
- `전주시완산구` 실황 1레코드, 단기예보 POP(강수확률) 3레코드 조회 성공.
- POP는 강수량이 아니다. 이 시험 지역을 PNU/스마트팜과 같은 위치라고 가정하지 않는다.

## 문헌·데이터 제약

- `data`의 토마토 길잡이: 364쪽. PDF 43/249쪽(인쇄 40/246쪽)의 생육단계별 수분장력 관리 범위가 다르다. 문맥·단계를 검토하고 규칙을 정해야 한다.
- 전주 물관리 지침서: 28쪽 스캔, 1999년 표지. PDF 12쪽의 토마토는 **노지** 기준이며 시설·수경에 직접 적용하지 않는다.
- 수분장력 kPa, 부호 있는 퍼텐셜, pF, 함수율 %를 혼동하거나 무근거 변환하지 않는다.
- 다른 출처의 자료를 지역명만으로 같은 농장이라고 결합하지 않는다. 과거 스마트팜 작기에 현재 기상을 붙이지 않는다.
- 문헌 해시는 `docs/reference_manifest.json`, 마지막 확인 환경은 `docs/runtime_manifest.json`에 있다.
